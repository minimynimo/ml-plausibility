# ml-plausibility

Code for a study of the **physical plausibility of machine-learning streamflow models** on CAMELS-US.
Four ML models (RF, XGB, TCN, LSTM), each trained per basin (*individual*), on all basins together
(*regional*) and, for the networks, regional fine-tuned per basin (*adapted*), are compared with a
per-basin calibrated conceptual model (HBV, MARRMoT). Beyond accuracy (KGE/NSE), every model is driven
with synthetic forcing (a six-year drought and record storms of increasing size) and scored on
plausibility checks for **mass balance**, **drought recession** and **flood response**.

The repository contains code only. Input data, model outputs and figures are not tracked; see [Data](#data).

## Study design

| | |
|---|---|
| Basins | 637 CAMELS-US basins with complete discharge, precipitation, temperature and PET from 1987-01-01 to 2006-12-31 (list: `basins/basin_sets.csv`) |
| Inputs | Daymet basin-mean P and T (mean of tmax/tmin), Priestley–Taylor PET computed from Daymet; 27 static CAMELS attributes for regional/adapted models |
| Periods | warm-up 1987, train ("cal") 1988–1997, validation 1998–2000 (early stopping / HP selection only), test 2001–2006 |
| Seeds | 5 per ML model and strategy (42–46); HBV one CMA-ES calibration (seed 42) on KGE |
| Drought scenario | P = 0 from 2001-01-01 to 2006-12-31, real T and PET |
| Flood scenarios | per basin, the largest daily P of 2001–2006 (`P_src`) is repeated on 1, 3 or 5 consecutive days with uplifts of 0, 10, 30, 50 %, after 10 dry days, starting 2001-01-11; T/PET are transplanted from the source event; a no-storm run gives the storm response ΔQ |

All dates, basin sets, seeds, scenario settings and hyperparameters are defined once in
[config/experiment.py](config/experiment.py). The check rules and the observation-based thresholds are in
[07_analysis/PLAUSIBILITY_CHECKS.md](07_analysis/PLAUSIBILITY_CHECKS.md).

## Repository layout

Numbered folders are run, in order; the other folders are libraries and settings.

| Folder | Contents |
|---|---|
| `01_data_prep/` | build every model input from the raw CAMELS-US download (run 1 → 6) |
| `02_run_driver/` | dependency-aware driver that runs tuning, training, checks, analysis and figures (03–08) unattended |
| `03_train/` | `trees.py` (RF/XGB, tune + final) and `nets.py` (TCN/LSTM, all strategies) |
| `04_hp_selection/` | hyperparameter selection for TCN and LSTM (regional and individual) |
| `05_hbv/` | HBV calibration and scenario runs in MATLAB (MARRMoT), and conversion to the common run format |
| `06_checks/` | completeness check of every run and scenario output |
| `07_analysis/` | evaluation basin set, all scores (`scoring.py`), SHAP attribution |
| `08_figures/` | one script per paper figure (`fig01_s01_accuracy.py` … `fig06_s04_ranking.py`) |
| `config/` | `experiment.py` (paths, design, hyperparameters), `plot_style.py` (figure colours, fonts, sizes) |
| `hsp/`, `features/`, `models/` | data access and run I/O, tree feature table, network architectures |
| `basins/` | `basin_sets.csv` (training pool, Newman-531 flag, evaluation set) |
| `data/`, `out/`, `fig/` | inputs, outputs, figures (created locally, not tracked) |

## Setup

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt          # Python 3.12; install the torch build that matches your CUDA
```

HBV additionally needs MATLAB and MARRMoT v2.1.2 (see [HBV](#5-hbv)). Figures use IBM Plex Sans if it is
installed or its `.ttf` files are put in `config/fonts/`; otherwise matplotlib falls back to DejaVu Sans.

Download the following and place them under `data/` (or set `HSP_DATA_ROOT` to another folder with the
same layout):

| Source | Place at |
|---|---|
| CAMELS-US time series v1.2 (`basin_timeseries_v1p2_metForcing_obsFlow.zip`; Newman et al., 2015), NSF NCAR, <https://doi.org/10.5065/D6MW2F4D> | unzip so that `data/camels_us/basin_dataset_public_v1p2/basin_mean_forcing/daymet/` and `.../usgs_streamflow/` exist |

## Running

All commands are run from the repository root. Outputs go to `out/` (runs, tuning, analysis tables,
logs) and figures to `fig/`; override with `HSP_OUT_ROOT` / `HSP_FIG_ROOT`.

### 1. Inputs

```bash
python 01_data_prep/1_create_forcing_csv.py 16     # [n_jobs]
python 01_data_prep/2_build_attribute_table.py
python 01_data_prep/3_basin_filter.py              # -> 637-basin training pool
python 01_data_prep/4_make_basin_sets.py           # -> basins/basin_sets.csv (already in the repo)
python 01_data_prep/5_create_mat_files.py 16
python 01_data_prep/6_verify_forcing.py            # asserts the scenario construction; must report 0 failing
```

`3_basin_filter.py` keeps canonical CAMELS gauges with gap-free data over 1987–2006 and removes the
basins in `EXCLUDED_BASINS` (`config/experiment.py`).

### 2. Models, analysis and figures (driver)

```bash
setsid nohup python 02_run_driver/driver.py > out/_driver/driver.out 2>&1 &
```

The driver (`02_run_driver/tasks.py`) runs, as resources allow (`HSP_CPU_TOTAL`, `HSP_GPU_SLOTS`):
RF/XGB tuning → regional TCN filter and window search → final runs of every model, strategy and seed (each
also producing all scenario outputs) → completeness check → evaluation set → scoring → SHAP → figures.
It can be stopped and restarted at any time; finished tasks are skipped. Every step can also be run by hand
with the commands listed in `tasks.py`.

### 3. Hyperparameter selection

- RF / XGB: `03_train/trees.py --mode tune` (grid search, median validation NSE) → `out/tuning/<MODEL>_<strategy>/`.
- Regional TCN: `04_hp_selection/select_tcn.py filters`, then `final` (run by the driver).
- Regional LSTM and individual TCN / LSTM: train the grid points with `03_train/nets.py` (`--hidden_size`,
  `--dropout`, `--num_filters`, `--seq_length`, `--n_basins` for the individual search subset), then run
  `04_hp_selection/select_lstm.py`, `select_tcn_individual.py` or `select_lstm_individual.py` with
  `hidden`/`filters` and then `final`.

The selected values are written to `config/experiment.py` by hand.

### 4. Analysis and figures by hand

```bash
python 06_checks/check_runs.py
python 07_analysis/eval_set.py
python 07_analysis/scoring.py
python 07_analysis/shap_attribution.py
bash 08_figures/run_all.sh                       # or a single figure: python 08_figures/fig04_drought.py
```

| Script | Figures | Tables |
|---|---|---|
| `fig01_s01_accuracy.py` | fig01 accuracy (KGE) by strategy; s01 calibration vs test | csv01, csv01b, csv01c, scsv02 |
| `fig02_s02_shap.py` | fig02 SHAP attribution; s02 tree families, Precip share by flow state | csv02 |
| `fig03_mass_balance.py` | fig03 volume error, water-balance violations, implied ET | csv03, csv03b |
| `fig04_drought.py` | fig04 late-drought flow, example hydrographs, recession timescales | csv04 |
| `fig05_s03_flood.py` | fig05 elasticity, response speed, flood checks; s03 flag examples and lag | csv05a, csv05d |
| `fig06_s04_ranking.py` | fig06 accuracy vs plausibility and ranking; s04 ranking sensitivity | scsv04 |

### 5. HBV

Get MARRMoT v2.1.2 (<https://github.com/wknoben/MARRMoT>), put its `Models/` and `Functions/` folders in
`05_hbv/MARRMoT/` (or set `MARRMOT_DIR`), and apply the patch that lets CMA-ES write its logs to an
absolute output path:

```bash
patch "05_hbv/MARRMoT/Functions/Optimisation functions/my_cmaes.m" < 05_hbv/marrmot_patch/my_cmaes.patch
MATLAB_BIN=/path/to/matlab nohup 05_hbv/parallel.sh 40 > /dev/null 2>&1 &     # [parallel MATLAB processes]
python 05_hbv/postprocess.py                                                   # after _MATLAB_FINISHED
```

The driver waits for the HBV run before the completeness check.

### Smoke test mode

`HSP_SMOKE=<n>` runs the pipeline on `n` basins with fewer seeds (basin sets and outputs go under
`HSP_OUT_ROOT`); `03_train/*.py --n_basins <n>` limits a single training run.

## Environment variables

| Variable | Default | Meaning |
|---|---|---|
| `HSP_DATA_ROOT` | `data/` | input data |
| `HSP_OUT_ROOT` | `out/` | runs, tuning, analysis tables, logs |
| `HSP_FIG_ROOT` | `fig/` | figures and figure tables |
| `HSP_BASIN_DIR` | `basins/` | `basin_sets.csv`, `hbv_failures.csv` |
| `HSP_FONT_DIR` | `config/fonts/` | optional `.ttf` files for the figures |

| `HSP_CPU_TOTAL`, `HSP_GPU_SLOTS` | `120`, `4` | driver resource limits |
| `MATLAB_BIN`, `MARRMOT_DIR`, `PYTHON` | `matlab`, `05_hbv/MARRMoT`, `python` | HBV / shell scripts |
